# Lab 3: Adaptive Remediation

**Tools:** Quantum Safe Remediator (QSR)

## Objectives

By the end of this lab you will be able to:

- Configure **Quantum Safe Remediator (QSR)** to target a legacy application
- Identify non-quantum-safe cryptographic calls within the application
- Apply adaptive remediation to replace vulnerable cryptography with quantum-safe alternatives
- Validate that the remediated application passes the cryptographic policy defined in Lab 2

## Estimated Duration

~45 minutes

## Prerequisites

Complete **[Lab 2: Analysis, Policy & Migration](../lab-02-analysis-policy-migration/index.md)** before starting this lab.
