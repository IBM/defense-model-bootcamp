# Lab Setup

## Required Materials

For this lab, you will need:
- Access to the ARGUS AI web interface (URL provided by instructor)
- The sample AAR document: `AAR_AngelFireUnclass.docx` (provided in lab materials)
- A modern web browser (Chrome, Firefox, or Edge recommended)

## Before You Begin

1. Ensure you have the `AAR_AngelFireUnclass.docx` file downloaded and accessible
2. Open your web browser and navigate to the ARGUS AI interface
3. Verify you can see the chat interface and document upload area

---

Once you have completed the setup steps above, you're ready to begin [Step 1: Upload AAR](./step-01-upload-aar.md).
