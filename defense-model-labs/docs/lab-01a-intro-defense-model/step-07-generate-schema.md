# Step 7: Generate Structured Schema Output

**Objective:** Convert the unstructured AAR document into a standardized JSON schema format.

## Instructions

1. In the chat input field, type:
   ```
   put this information into a schema
   ```
2. Send the message and wait for ARGUS AI to process the request
3. Observe the schema generation process

## Expected Result

ARGUS AI will generate a structured JSON output that organizes all extracted information according to a predefined AAR schema, including:
- Document metadata (title, date, classification, point of contact)
- Operation details (name, location, objectives, timeline)
- Participants (personnel, units, organizations)
- Equipment inventory with Janes enrichment data
- Execution summary and events timeline
- Observations and lessons learned
- Recommendations (immediate, short-term, long-term)
- Environmental conditions

## 💡 Tip

Schema-based outputs enable automated processing, database integration, and interoperability with other defense systems.
