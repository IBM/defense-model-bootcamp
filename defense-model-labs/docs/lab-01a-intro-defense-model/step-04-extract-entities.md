# Step 4: Extract Entities from the Document

**Objective:** Identify and extract specific entities (equipment, locations, personnel, organizations) mentioned in the AAR.

## Instructions

1. In the chat input field, type:
   ```
   look up entities from this doc
   ```
2. Send the message and wait for ARGUS AI to process the request
3. Observe the entity extraction process

:::warning[Please Note]
The entity extraction process can take a **few minutes**, depending on the size of the document and the number of entities identified.
:::
![Look up entities process](/img/lab-01/look-up-entities-process.png)

## Expected Result

ARGUS AI will identify and categorize entities found in the document, such as:
- **Equipment:** Aircraft, vehicles, weapon systems, sensors
- **Locations:** Geographic coordinates, bases, operational areas
- **Personnel:** Names, ranks, positions
- **Organizations:** Units, commands, agencies
- **Dates and Times:** Operation timeline events

## 💡 Tip

Entity extraction is a fundamental capability in information processing. It transforms unstructured text into structured data that can be searched, filtered, and analyzed.
