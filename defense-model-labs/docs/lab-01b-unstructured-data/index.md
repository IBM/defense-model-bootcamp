# Lab 1B: Unstructured Data Processing with IBM Defense Model

**Tools:** IBM Defense Model, IBM's Unstructured Data Processing capabilities, including Unstructured Data Curation (UDC) and Unstructured Data Integration (UDI) within IBM watsonx.data

## Overview

### Lab Overview

This lab demonstrates one of the real-world implementations of a Defense Model to automate metadata enrichment for a collection of defense-related documents. This capability significantly improves information retrieval, intelligence analysis, and question-and-answer (Q&A) workflows. In this lab, users work with IBM technologies integrated with Defense Model to automatically extract key entities, catalog information, and analyze content with enhanced precision. The solution addresses the challenge of managing large volumes of unstructured defense data by converting it into structured, searchable, and actionable formats.

- **Duration:** 30–45 minutes
- **Difficulty:** Beginner
- **Prerequisites:** Complete **[Lab 1A: Introduction to IBM Defense Model with ARGUS AI](../lab-01a-intro-defense-model/)** before starting this lab.

## 🎯 What You'll Learn

- Reduce manual effort required for tagging, categorization, and dissemination of defense data for multi-domain operations
- Build operator-driven pipelines for document ingestion
- Analyze document metadata and classify documents
- Use natural language to query document collections
- Extract and structure key entities from unstructured text
- Improve information retrieval and enhance the quality and relevance of responses

This lab highlights how AI-driven metadata enrichment enables defense organizations to efficiently unlock value from unstructured data. By converting documents into structured, searchable information.
