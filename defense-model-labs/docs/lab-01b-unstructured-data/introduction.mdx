## Why focus on automating ingestion of unstructured content using IBM Defense Model?

<p><a href="https://www.ibm.com/products/watsonx-ai/defense-model" target="_blank" rel="noopener noreferrer">https://www.ibm.com/products/watsonx-ai/defense-model</a></p>

<div><p>According to Gartner (via Research World, 2025), 80–90% of all newly generated enterprise data is unstructured including PDFs, contracts, audio logs, emails, and other non-tabular formats. Unlocking the value of this unstructured content is rapidly becoming the competitive differentiator for trustworthy, enterprise-grade GenAI applications.</p></div>

<ul>
  <li><strong>Design end-to-end preprocessing pipelines visually.</strong><br />Build complete unstructured data flows using an intuitive drag-and-drop interface with pre-built operator nodes—no heavy coding required.</li>
  <li><strong>Simplify RAG data preparation.</strong><br />Each operator node represents a discrete transformation or processing step, making it easy to prepare high-quality unstructured data for Retrieval-Augmented Generation (RAG) use cases.</li>
  <li><strong>Built for every skill level.</strong><br />An intuitive UI empowers data engineers, data scientists, and analysts alike to quickly ingest and process unstructured data with minimal onboarding.</li>
  <li><strong>Connect to the data sources you already use.</strong><br />Ingest unstructured data from local documents and popular enterprise systems, including Amazon S3, Box, FileNet P8, SharePoint, Slack, Microsoft OneDrive, and IBM Cloud Object Storage.</li>
  <li><strong>Seamless integration with vector and search stores.</strong><br />Store processed outputs directly in Milvus, watsonx.data (Milvus), or Elasticsearch to power downstream retrieval and GenAI workloads.</li>
  <li><strong>Extend and automate with a Python SDK.</strong><br />Advanced users and developers can programmatically access the same preprocessing capabilities using the Python SDK—ideal for automation, customization, and integration into existing data and AI pipelines.<br /><strong>GitHub:</strong> https://github.com/IBM/udi-sdk</li>
</ul>

## Architecture

<p><img src={require('@site/static/img/wxdi_arch.png').default} alt="Architecture" style={{width: '100%', height: 'auto', margin: '0 auto', display: 'block'}} /></p>

<p>This hands-on lab introduces users to Unstructured Data Processing, which includes both Unstructured Data Curation (UDC) and Unstructured Data Integration (UDI) capabilities within IBM watsonx.data Integration and IBM watsonx.data intelligence. Participants will configure connections to various data sources (such as Box, Presto, and Milvus) and build a configurable, operator-driven pipeline that ingests unstructured PDF documents, analyzes their metadata, and classifies them into relevant document groups</p>

<p>ARGUS AI serves as your intelligent assistant for document analysis, combining the conversational ease of modern AI chatbots with the precision and reliability required for defense applications.</p>
