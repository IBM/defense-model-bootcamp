## Learning Objectives

By the end of this lab, you will be able to:

<ul className="checkbox-list">
  <li><input type="checkbox" /> Understand Unstructured Data Processing, which includes both Unstructured Data Curation (UDC) and Unstructured Data Integration (UDI) capabilities within IBM watsonx.data Integration and IBM watsonx.data intelligence.</li>
  <li><input type="checkbox" /> Use ARGUS AI and UDC to build a configurable, operator-driven pipeline that ingests unstructured PDF documents</li>
  <li><input type="checkbox" /> Analyze metadata and classify a set of documents into relevant document groups.</li>
  <li><input type="checkbox" /> Interact with the corpus in Natural language to get summary statistics related to the different concepts in the documents</li>
  <li><input type="checkbox" /> Recognize the value of AI-powered document analysis in defense operations</li>
</ul>
