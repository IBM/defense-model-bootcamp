## ⚙️ Hands-On: Configure the Model Comparison Run

Before you can evaluate the fine-tuned model, you need to set up the comparison. In this step, you'll navigate to the **Fine-tuning Lab**, select the two models to compare, upload the evaluation dataset, and launch the comparison run.

### What Is the Evaluation Dataset?

The evaluation dataset is a CSV file containing labeled questions used to test both models side by side. It is **not** training data — the models have never seen these questions before. Each row has two columns:

- **Question** — A natural language query (e.g., "Which SAM's are manufactured by JSC KB Radar?")
- **Category** — The correct expected answer category (e.g., `equipment`, `installations`, `inventory`)

The comparison run sends each question to both models and measures how often each one predicts the correct category.

## 🎯 Activity 1: Open the Fine-Tuning Lab and Review the Configuration Form

### Step 1: Navigate to the Fine-Tuning Lab

On the left side menu, click **"Fine-tuning Lab"**. The **Model Performance Comparison** page loads, showing the **Configure Model Comparison** form. Both model dropdowns are blank and the validation dataset upload area is empty — ready to be configured.

![Configure Model Comparison form with empty model dropdowns and upload area](/img/lab-03/step1_1.png)

### Step 2: Select Model 1 — Fine-Tuned Model

Click the **Model 1** dropdown (highlighted with a red box). Select **"Fine-tuned Model"** from the list. This is the model that was customized on defense domain data and whose performance you want to measure.

![Model 1 dropdown open, ready to select Fine-tuned Model](/img/lab-03/step1_2.png)

### Step 3: Select Model 2 — Base Model

Click the **Granite 4 Small / Model 2** dropdown (highlighted with a red box). Select **"Base Model"** from the list. This sets up the side-by-side comparison — the fine-tuned model against the unmodified base model.

![Model 2 dropdown open with Base Model being selected](/img/lab-03/step1_3.png)

## 🎯 Activity 2: Obtain the Evaluation Dataset

### Step 4: Download the Sample Evaluation Dataset

With both models selected, locate the **Upload Validation Dataset (CSV)** section. Click **"↓ Download sample dataset"** (highlighted with a red box) to download the pre-prepared evaluation CSV file (`fine_tuning_sample.csv`) to your local machine.

![Configuration form with Download sample dataset link highlighted](/img/lab-03/step1_4.png)

### Step 5: Review the Evaluation Dataset Contents

Open the downloaded `fine_tuning_sample.csv` file to review its contents. The file contains **13 labeled questions** across 6 defense entity categories: installations, equipment, organizations, inventory, military-groups, and events. Each row has a **Question** and the correct **Category** label. Click **Download** (highlighted with a red box) to save the file locally if you haven't already.

![fine_tuning_sample.csv open in browser showing 13 labeled questions with Question and Category columns](/img/lab-03/step1_5.png)

## 🎯 Activity 3: Upload the Evaluation Dataset and Run the Comparison

### Step 6: Click the Upload Area to Open the File Picker

Back in the **Configure Model Comparison** form, click the upload drop zone (highlighted with a red box) labeled **"Click to upload or drag and drop — CSV file with validation data"**. This opens the file picker.

![Upload drop zone highlighted, ready to receive the validation CSV](/img/lab-03/step1_6.png)

### Step 7: Select fine_tuning_sample.csv from Your Downloads

In the file picker, navigate to your **Downloads** folder and select **fine_tuning_sample.csv** (913 bytes, shown highlighted in blue). Click **Open** to upload it.

![macOS file picker open showing fine_tuning_sample.csv selected in Downloads folder](/img/lab-03/step1_7.png)

### Step 8: Confirm Validation Data Loaded and Run the Comparison

After upload, the form shows a **"✓ Validation Data Loaded"** confirmation panel with the dataset summary: **13 total questions**, **6 unique categories**, and **0.9 KB** file size. The category distribution chips show how questions are spread across Installations (4), Equipment (2), Organizations (2), Inventory (2), Military-Groups (2), and Events (1). Review the summary, then click **RUN COMPARISON** (highlighted with a red box) to launch the evaluation.

![Validation data loaded summary with category distribution and RUN COMPARISON button highlighted](/img/lab-03/step1_8.png)
