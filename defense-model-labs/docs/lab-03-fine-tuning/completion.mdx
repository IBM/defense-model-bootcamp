## 💡 Key Takeaways

<div style={{
  background: '#FFF8E1',
  padding: '24px',
  borderRadius: '4px',
  margin: '24px 0',
  borderLeft: '4px solid #FDD13A',
  color: '#856404'
}}>
  <h3 style={{marginTop: 0}}>Remember These Core Concepts:</h3>
  <ul style={{marginBottom: 0, lineHeight: '2', fontSize: '1.05rem'}}>
    <li><strong>Evaluation Data Must Be Held Out:</strong> Never evaluate a model on questions it saw during training — results will be inflated and misleading</li>
    <li><strong>Iterate and Evaluate:</strong> Fine-tuning is not a one-time event — it's an ongoing cycle of data, training, and evaluation</li>
    <li><strong>Domain Adaptation Matters:</strong> A fine-tuned model trained on defense data will outperform a general model on defense tasks — +7.69% in this lab</li>
    <li><strong>Governance is Non-Negotiable:</strong> Deploying fine-tuned models operationally requires rigorous testing, approval, and monitoring</li>
    <li><strong>Category-Level Analysis Is Essential:</strong> Overall accuracy can mask weaknesses — always review per-category results to find where the model still struggles</li>
  </ul>
</div>
