# Lab 3: Fine Tuning with IBM Defense Model

**Tools:** IBM Defense Model, ARGUS AI Fine-tuning Lab

## Overview

### Lab Overview

- **Duration:** ~90 minutes
- **Difficulty:** Intermediate
- **Prerequisites:** Complete **[Lab 2: IBM Defense Model Factchecker](../lab-02-factchecker/)** before starting this lab.

### Lab Steps Overview

This lab consists of 3 hands-on steps:

1. **[Lab Environment Setup](./setup)** - Access the demo environment and navigate to the Fine-tuning Lab
2. **[Configure Model Comparison](./step1)** - Select models, upload the evaluation dataset, and launch the comparison run
3. **[Run Comparison](./step2)** - Wait for the comparison run to complete across both models
4. **[Evaluate Model](./step3)** - Explore the results dashboard and analyze fine-tuned vs base model performance
5. **[Completion](./completion)** - Lab summary and next steps

### What You'll Learn

Through these steps, you'll experience:

- **Fine-tuning concepts** and when to apply domain adaptation for defense use cases
- **Model Performance Comparison** tool configuration — selecting models and uploading an evaluation dataset
- **Evaluation vs training data** — understanding the difference and why it matters
- **Results dashboard analysis** — accuracy scores, category breakdowns, error listings, and key insights
- **The IBM Defense Model** demonstrating measurable improvement through domain-specific fine-tuning

---

## Learning Objectives

By the end of this lab, you will be able to:

- Understand the concepts and techniques behind fine-tuning large language models for defense use cases
- Configure the Model Performance Comparison tool by selecting models and uploading an evaluation dataset
- Understand the difference between training data and evaluation data in the context of fine-tuning
- Analyze the comparison dashboard — accuracy scores, category breakdowns, error listings, and key insights
- Recognize the value of domain-adapted AI models in defense and intelligence operations
