# Step 2: Run the Model Comparison

**Objective:** Wait for the comparison run to complete across both models.

## Instructions

After clicking **RUN COMPARISON** in Step 1, ARGUS AI begins evaluating all 13 questions against both models. The page transitions to a **Processing Model Comparison** screen — do not close or refresh the page while it runs.

![Processing Model Comparison screen showing 4-step progress tracker at 5%](/img/lab-03/step2_1.png)

The progress tracker shows four sequential stages:

1. **Loading validation dataset** — The uploaded CSV is parsed and questions are queued
2. **Running Model 1 predictions** — Each question is sent to the Fine-tuned Model and the predicted category is recorded
3. **Running Model 2 predictions** — The same questions are sent to the Base Model
4. **Generating comparison metrics** — Accuracy scores, category breakdowns, error listings, and the performance delta are calculated

## Expected Result

The full run completes in **15–30 seconds**. When all four stages finish, you are automatically taken to the results dashboard.

## What Is Happening During the Run?

1. **Classification Inference** — Each question is sent to both models as a prompt. Each model returns its predicted category label (e.g., `equipment`, `inventory`, `installations`).
2. **Ground-Truth Comparison** — The predicted category is compared against the correct label in the CSV. A match counts as correct; a mismatch is recorded as an error.
3. **Metric Aggregation** — Results are aggregated per category and overall: accuracy, category-wise accuracy, error count, and performance delta.
4. **Report Generation** — The dashboard (score cards, bar chart, radar, category details, key insights) is assembled from these aggregated results.

## 💡 Tip

Use the wait time to think through these questions:

- Will the fine-tuned model outperform the base model on all categories, or just some?
- Which categories do you expect to show the biggest improvement after fine-tuning?
- What accuracy threshold would matter in a real deployment — 1%? 5%? 10%?
- If the fine-tuned model performs worse on a category, what might explain that?

## 📝 Best Practices

- Always use held-out questions the model has never seen during training
- Include enough examples per category to get a reliable accuracy reading
- Keep the page open until the run finishes — refreshing will cancel the comparison and require restarting
- Run the same evaluation dataset against multiple model versions to track improvement over time
