# Lab 3: Fine Tuning with IBM Defense Model

This lab introduces you to fine-tuning the IBM Defense Model using the custom ARGUS AI fine-tuning interface.

## 📚 Lab Contents

This lab includes:

- **[Overview](./overview)** - Lab objectives and learning outcomes
- **[Introduction](./introduction)** - Why fine-tune defense models
- **[Lab Setup](./setup)** - Environment configuration and access
- **[Step 1: Configure Model Comparison](./step1)** - Select models, upload the evaluation dataset, and launch the comparison run
- **[Step 2: Run Comparison](./step2)** - Wait for the comparison run to complete across both models
- **[Step 3: Evaluate Model](./step3)** - Explore the results dashboard and analyze fine-tuned vs base model performance
- **[Completion](./completion)** - Lab summary and next steps

## 🎯 What You'll Learn

- Understand fine-tuning concepts and when to apply them for defense use cases
- Configure the Model Performance Comparison tool in the ARGUS AI Fine-tuning Lab
- Upload and understand an evaluation dataset used to benchmark both models
- Analyze accuracy scores, category breakdowns, and error listings in the comparison dashboard
- Recognize the value of domain-adapted AI models in defense and intelligence operations

## ⏱️ Duration

~90 minutes
