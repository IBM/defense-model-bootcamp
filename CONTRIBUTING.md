# Contributing to GCM Lab Guides

Thanks for contributing to the GCM Lab Guides.

For the full contribution guide — including how to set up locally, add a new lab, and follow file naming conventions — see the **[Contributing page on the lab site](https://IBM.github.io/gcm-bootcamp/docs/contributing)**.

## Quick Start

```bash
git clone https://github.com/IBM/gcm-bootcamp.git
cd gcm-bootcamp/gcm-labs
npm install
npm start
```

The site is served at `http://localhost:3000/gcm-bootcamp/`.

## Publishing

Push to `main`. GitHub Actions builds and deploys to GitHub Pages automatically. Check the [Actions tab](https://github.com/IBM/gcm-bootcamp/actions) to confirm status.
