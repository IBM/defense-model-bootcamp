Step 1: Configure the Model Comparison

Objective: Set up the Model Performance Comparison run by selecting both models, downloading the evaluation dataset, uploading it, and launching the comparison.

What Is the Evaluation Dataset?​

The evaluation dataset is a CSV file containing labeled questions used to test both models side by side. It is not training data — the models have never seen these questions before. Each row has two columns:

  • Question — A natural language query (e.g., "Which SAM's are manufactured by JSC KB Radar?")
  • Category — The correct expected answer category (e.g., equipment, installations, inventory)

The comparison run sends each question to both models and measures how often each one predicts the correct category.

Instructions​

Step 1: Navigate to the Fine-Tuning Lab​

On the left side menu, click "Fine-tuning Lab". The Model Performance Comparison page loads, showing the Configure Model Comparison form. Both model dropdowns are blank and the validation dataset upload area is empty — ready to be configured.

Step 2: Select Model 1 — Fine-Tuned Model​

Click the Model 1 dropdown. Select "Fine-tuned Model" from the list. This is the model that was customized on defense domain data and whose performance you want to measure.

Step 3: Select Model 2 — Base Model​

Click the Granite 4 Small / Model 2 dropdown. Select "Base Model" from the list. This sets up the side-by-side comparison — the fine-tuned model against the unmodified base model.

What to check:

  • Model 1 is set to Fine-tuned Model
  • Model 2 is set to Base Model

Step 4: Download the Sample Evaluation Dataset​

With both models selected, locate the Upload Validation Dataset (CSV) section. Click "↓ Download sample dataset" to download the pre-prepared evaluation CSV file (fine_tuning_sample.csv) to your local machine.

Step 5: Review the Evaluation Dataset Contents​

Open the downloaded fine_tuning_sample.csv file to review its contents. The file contains 13 labeled questions across 6 defense entity categories: installations, equipment, organizations, inventory, military-groups, and events. Each row has a Question and the correct Category label.

What to check:

  • The file has two columns: Question and Category
  • There are 13 rows of labeled questions
  • Installations appears most frequently (4 questions); events has only 1

Step 6: Click the Upload Area to Open the File Picker​

Back in the Configure Model Comparison form, click the upload drop zone labeled "Click to upload or drag and drop — CSV file with validation data". This opens the file picker.

Step 7: Select fine_tuning_sample.csv from Your Downloads​

In the file picker, navigate to your Downloads folder and select fine_tuning_sample.csv. Click Open to upload it.

Step 8: Confirm Validation Data Loaded and Run the Comparison​

After upload, the form shows a "✓ Validation Data Loaded" confirmation panel with the dataset summary: 13 total questions, 6 unique categories, and 0.9 KB file size. Review the summary, then click RUN COMPARISON to launch the evaluation.

What to check:

  • The confirmation panel shows 13 total questions and 6 unique categories
  • The RUN COMPARISON button is active (not greyed out)

Expected Result​

The comparison run is launched. ARGUS AI transitions to the Processing Model Comparison screen showing a 4-step progress tracker. When all stages complete, the results dashboard loads automatically.

📝 Note​

The evaluation dataset uses held-out questions — these 13 questions were not part of the fine-tuning training data. This ensures the accuracy scores reflect real performance on unseen data, not memorization.

💡 Troubleshooting​

  • Upload Failed — Check that the file is a CSV with exactly two columns named Question and Category
  • Validation Error — Ensure there are no empty cells or extra columns in the CSV
  • Models Not Appearing — Refresh the page and re-open the Fine-tuning Lab
  • RUN COMPARISON Stays Grey — Both model dropdowns must be filled and a valid CSV must be loaded before the button becomes active
